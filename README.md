# AI星露谷 · AI Stardew Valley

> 让鹈鹕镇的村民真正“活”起来。

**当前版本**：2.0.0-alpha.1（开发中）  
**运行环境**：Stardew Valley 1.6+ / SMAPI 4.0+  
**作者**：远古牛哥  
**N 网 mod**：[尾号 41031](https://www.nexusmods.com/stardewvalley/mods/41031)（2.0 及后续版本继续使用该尾号）

AI星露谷是一个《星露谷物语》的 AI 扩展 mod。村民会用 AI 和你聊天，记得你做过的事，彼此传八卦、在路边聊天、在群里发消息，还会约你见面、来农场帮忙、写信送礼；镇上也有会波动的市场、委托板、周报，村民有自己的钱和家当。

## 功能一览

### 对话与记忆

- **AI 对话**：每个村民按自己的性格、与你的交情、天气和最近发生的事说话，可以多轮来回；回复会影响好感。
- **长期记忆**：对话历史、情感记忆、负面记忆、你送过什么、答应过什么，过几天还会提起。
- **关系变化**：里程碑、名声、性格演变；说话太冲会结仇，好好说话能慢慢化解。
- **孩子也会说话**：你的孩子会走路以后，每天第一次搭话时按家里的情况说一句。
- **自定义角色卡**：改写任何村民的性格和说话方式，编辑时可以先试聊；改过的人设会影响对话、群聊和来信。还有“我的设定”，决定村民怎么称呼你、怎么看你。

### 村民之间

- **八卦**：你做的事会变成镇上的八卦，一个传一个，传着传着还会走样；八卦树能看到是谁告诉了谁。
- **所见所闻**：村民会注意到你当着他们的面做的事，看见的人当天开口就从这件事说起；深夜和人一起走也会被旁人看到。
- **主动找你**：村民会走过来搭话，也会陪你钓鱼。
- **路边聊天**：村民站在一起时会自己聊起来，气泡冒在头顶，游戏不暂停；路过的人能加入，你按 T 插话。
- **心情与社交网**：每个村民有当天的心情，村民之间有关系网，也会发生自己的小事。

### 手机和界面

- **手机实物**：背包里有一部手机，拿在手上点一下就能打开，有未读时直接进那条聊天。
- **来消息提示**：屏幕下方滑出小手机，点一下进那条聊天，右键收起。
- **统一的外壳**：按 F9 或用手机打开，分今日、社交、世界、应用、设置。
- **AI 状态**：设置里能看现在好不好用、今天用了多少、最近为什么失败，可以当场测试连接。
- **信使**：和村民一对一发消息、发照片，聊天里直接出约见卡片，每位村民分开计数。
- **居民群**：像 QQ 群一样的全镇群聊，村民自己也会在群里聊。
- **应用**：大家都在哪（按地点或在地图上看村民、今天的路线和几点回家）、鹈鹕图（村民发帖、点赞、评论的照片墙）、心情预报、八卦树、村庄关系网、评价、年度回顾、日程、星座、天文台、分类广告、谁说的、Junimo 宠物。内容都来自镇上真实发生的事。
- **输入法候选框**：让输入法自己画候选字，中文输入更顺。

### 信件、日记和礼物

- **来信**：村民给你写信，生日也会收到祝福。
- **日记**：每天一页，记下你和镇上发生的事，可以翻开日记本看。那晚 AI 没写成的话，第二天能点重试补上。
- **村民日记**：在村民页翻开某位村民的日记，看 TA 对你的感觉、今天的心事、想跟你说的、托你办的事、卷进的小剧场、和别人的关系、这些日子的变化、听信的传闻。
- **有名字的礼物**：村民送的东西有 AI 起的名字和一句亲口说的话，信里也能附。

### 约定和同伴

- **AI 提议**：聊完弹确认卡片（跟随、干活、约见、送礼），答应了就真的发生。
- **定时定点约见**：村民按真实路程走过去等你，守约有奖励，失约有代价。
- **日程改写**：约好的时间段里村民去指定地点，之后回到自己的日程。
- **邀约出游**：约村民出去逛，完成后加好感。
- **婚后伴侣剧情**：伴侣隔几天写一段小故事：信、请求、见面、有话想说。
- **跟随和帮工**：配合 The Stardew Squad，村民可以跟着你下矿、按心数收费干活、约好时间上门；帮工页能看到今天谁来、干什么、进度、花了多少、退了多少。

### 小剧场

- **故事线**：镇上发生一段段小故事，你参与推动结局，结局可以在游戏里演出来。
- **场景事件**：117 段写好的村民日常小场景，可以撞见，也可以旁听。
- **拜托和承诺**：村民托你办事、向你要东西，办完有一小段感谢戏。
- **离开小镇**：关系走到尽头时可能有人离开小镇（可调概率，孩子和配偶不会）。
- **节日对话**：节日里也是 AI 对话，可以邀请跳舞和组队；散场后大家还会回味。

### 小镇经济

- **市场行情**：出货价每天波动，加工品跟着原料走。
- **委托板（村民→玩家）**：收购、采集、求矿、来坐坐，报酬按物品原价。
- **托村民办事（玩家→村民）**：找东西、代买、做菜、转送、干农活，报酬先托管。
- **村民账本**：钱包、存款、随身物品、家当、流水；会逛店、存钱、互相借钱，手头紧时按性格想办法（卖唱、打零工、登广告）。你也可以向村民借钱，或者在酒吧赊账。
- **家当会消耗**：家当每周用掉一些，AI 礼物优先从家当里挑。
- **分类广告**：AI 按各人口气写；离婚卖婚纱、被扒窃登寻物，有实物的可以直接买下。
- **《鹈鹕镇周报》**：AI 按最近的八卦写新闻，核对事实，带行情和委托，可以翻往期；只有单一来源的消息写成未经证实。
- **对话消耗时间**：聊完关掉对话框后钟一格格走，最晚到 25:50。

### 分寸

- **儿童保护**：孩子不进群聊、约见、帮工、委托，也不会有感情戏。
- **成人内容默认关闭**：见下文“成人 mod”。私密时刻只记地点，不记内容。

### 快捷键

| 键 | 作用 |
|---|---|
| F9 | 打开外壳 |
| F6 | 八卦和日记 |
| F7 | 我的设定 |
| T | 地图群聊插话，或和身边的人聊起来 |

都可以在 Generic Mod Config Menu 或 `config.json` 里改。

## 兼容与联动

AI星露谷尽量直接从游戏数据里读取其他 mod 的内容，而不是为每个 mod 写死适配；同时对一些大型扩展和联动 mod 做了专门处理。

### 大型扩展与 NPC mod

- **星露谷扩展（SVE / Stardew Valley Expanded）**：SVE 的村民、作物、物品、住所、日程和礼物喜好都能接入；SVE 村民有单独的人设。
- **东斯卡普（East Scarp）、里奇赛德村（Ridgeside Village）等大型扩展**：新增的村民、作物、物品、日程等内容从游戏数据读取，不需要单独适配。
- **任意通过内容包向 `Data/Characters` 添加村民的 mod**：可以由 AI 接管，内容包可以写自己的人设字段。支持社区的 AI 排除名单，尊重不希望角色被 AI 驱动的作者。在 设置 > 常用 > 村民和 NPC mod 里能看到每位村民用不用 AI、为什么，也能关掉某位村民、选用哪些 mod 的村民。
- **Beach Episode**：沙滩排球锦标赛和鹦鹉之夜有节日对话。

### 联动 mod

- **The Stardew Squad（星露谷小队）**：同伴跟随、帮工、上门。发布包已内置带 API 的版本；自己编译时需要另装带 API 的版本，没有时这部分功能不可用，其他功能不受影响。
- **Stardew Thief（搜打撤）**：只读观察，不改它的行为。看见的人会找你理论，失主发现少了东西，镇上会传开。
- **Generic Mod Config Menu**：装了就能在里面改设置。

### 成人 mod（可选）

- 专门识别 **Xtardew、Valley Girls、LAtardew、Polyamory Sweet** 的事件和对话；数据里只有识别信息，没有事件或对话原文。
- 成人模块默认关闭，需要在设置里手动开启。
- 只有玩家自行安装对应成人 mod 并主动开启时，相关联动才会出现；没安装时自动跳过，不会报错。
- 本项目本身不包含成人内容，也不会主动触发成人 mod 的事件；相关事件仍由原 mod 按自己的条件触发。

### 自动关闭原则

- 所有联动都会先检测目标 mod 是否已加载；没装就跳过，相关按钮和提示不会出现。
- 世界模块、同伴模块、成人模块都可以在设置里单独关闭。

## 安装与运行

1. 安装 [SMAPI 4.0+](https://smapi.io/)。
2. 将发布包解压到游戏的 `Mods` 文件夹（包里已含 The Stardew Squad）。[Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915) 是前置，需要另外安装，包里不带；没装时 AI 功能和 Squad 主体照常运行，但 Squad 的坐姿贴图和海莉、哈维的同伴内容包不会加载。
3. 启动游戏。发布版首次需要 AI 时在游戏内注册或登录账号；也可以跳过登录，村民会先说游戏原来的台词。
4. 想使用自己的 AI 服务时，到 设置 > 常用 > AI 连接 选择自己的网关，填入 API 地址与密钥（OpenAI 兼容接口，本地模型也可以），可以当场测试连接。

> 2.0 目前仍处于 alpha 开发阶段，接口、配置和存档结构可能继续调整。

## 从源码编译

需要 .NET 8 SDK（测试在 net8.0 上跑）和 .NET 6 目标包；编译 mod 还需要装好 SMAPI 的游戏目录。

```bash
dotnet build AISV.sln -c Release -p:GamePath="/path/to/Stardew Valley"
```

编译结果在 `bin/AIStardewValley`，放进游戏的 `Mods` 文件夹就能用。源码里没有服务器连接文件（`assets/connection.dat`），自己编译的版本只能用自己的 AI 网关。

运行单元测试（不需要启动游戏）：

```bash
dotnet test tests/AISV.Core.Tests
```

## 路线图

以下内容为后续开发计划，正在逐步实现；顺序、细节和上线时间可能根据开发情况调整。

- **自定义 NPC 创建**：在游戏里创建属于自己的村民，设定名字、外貌、性格、住所等。
- **自定义 NPC 角色卡（自动接入 AI）**：为自定义 NPC 编写角色卡，保存后自动接入 AI 对话、记忆与关系系统。
- **配偶自定义日程**：为配偶安排专属日程，让婚后生活更符合你的设定。
- **更鲜活的世界**：村民之间会争吵、斗殴，关系变化会引发后续事件。
- **更具可玩性的商业活动与经济系统**：加入商业竞争、经营压力和破产风险。
- **我来当领导**：AI 村民会投票决定镇长，玩家可以参与竞选、拉票并影响结果。
- 更多内容陆续补充……

> 路线图不代表当前版本已经实现，具体内容与优先级以实际开发进度为准。敬请期待。
