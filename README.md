# AI星露谷 · AI Stardew Valley

> 让鹈鹕镇的村民真正“活”起来。

**当前版本**：0.3.0（开发中）  
**运行环境**：Stardew Valley 1.6+ / SMAPI 4.0+  
**作者**：远古牛哥  
**N 网 mod**：[尾号 41031](https://www.nexusmods.com/stardewvalley/mods/41031)（这个版本及后续版本继续使用该尾号）

AI星露谷是一个《星露谷物语》的 AI 扩展 mod。村民会用 AI 和你聊天，记得你做过的事，彼此传八卦、在路边聊天、在群里发消息，还会约你见面、来农场帮忙、写信送礼；镇上也有会波动的市场、委托板、周报，村民有自己的钱和家当。

## 功能一览

> 新玩法（农夫小超市、亲吻圆盘、我先开口、宠物心里话、和孩子聊天、孩子离家出走、配偶的一天）的图文说明见 [新功能指南](docs/新功能指南.md)。

### 对话与记忆

- **AI 对话**：每个村民按自己的性格、与你的交情、天气和最近发生的事说话，可以多轮来回；回复会影响好感。
- **长期记忆**：对话历史、情感记忆、负面记忆、你送过什么、答应过什么，过几天还会提起。
- **关系变化**：里程碑、名声、性格演变；说话太冲会结仇，好好说话能慢慢化解。
- **和孩子聊天**：孩子会走路以后可以多轮聊天，说话像个孩子，不谈恋爱、不谈钱；每个孩子有自己的角色卡。也可以改成每天只说一句，或者完全交给游戏原来的台词。
- **我先开口**：打开设置后，点村民时对话框先空着，你先说；有要紧事的村民（比如想托你办事）仍然会先开口。
- **亲吻还是聊天**：婚后点配偶时弹一个小圆盘，选亲吻（室友是拥抱）或聊天；按住 Alt（手柄 LB）点就是游戏原来的互动。
- **宠物的心里话**：猫狗偶尔在头顶冒一句灰色的心里话，跟今天有没有被摸、水盆有没有水、天气有关；只冒泡，不能对话。
- **自定义角色卡**：改写任何村民的性格和说话方式，编辑时可以先试聊；改过的人设会影响对话、群聊和来信。还有“我的设定”，决定村民怎么称呼你、怎么看你。

### 村民之间

- **八卦**：你做的事会变成镇上的八卦，一个传一个，传着传着还会走样；八卦树能看到是谁告诉了谁。
- **所见所闻**：村民会注意到你当着他们的面做的事，看见的人当天开口就从这件事说起；深夜和人一起走也会被旁人看到。
- **主动找你**：村民会走过来搭话，也会陪你钓鱼。
- **路边聊天**：村民站在一起时会自己聊起来，气泡冒在头顶，游戏不暂停；路过的人能加入，你按 T 插话。
- **心情与社交网**：每个村民有当天的心情，村民之间有关系网，也会发生自己的小事。

### 手机和界面

- **手机实物**：背包里有一部手机，拿在手上点一下就能打开，有未读时直接进那条聊天。
- **来消息提示**：信使和居民群的新消息都由屏幕下方滑出的小手机提示，点一下进那条聊天，右键收起。
- **统一的外壳**：按 F9 打开，分今日、社交、世界、应用、设置。
- **手机**：按 J 或用手机物品打开竖屏手机，主屏上一排排图标，里面是同样的内容；窄屏下村民和设置改成先看列表再点进去。
- **农场电脑**：罗宾店里卖的家具，摆在屋里右键开机，有开机动画和桌面。
- **个性化**：手机和电脑桌面有春日草地、林间黄昏、星空小屋三张会动的壁纸；界面有木屋、森林、星夜三种外观，外壳、对话框和群聊一起换。
- **AI 状态**：设置里能看现在好不好用、今天用了多少、最近为什么失败，可以当场测试连接。
- **信使**：和村民一对一发消息、发照片，聊天里直接出约见卡片，每位村民分开计数。
- **居民群**：像 QQ 群一样的全镇群聊，村民自己也会在群里聊。
- **应用**：大家都在哪（按地点或在地图上看村民、今天的路线和几点回家）、家谱（一家家的亲属关系和最近相处得怎么样）、鹈鹕图（村民发帖、点赞、评论的照片墙）、心情预报、八卦树、村庄关系网、评价、年度回顾、日程、星座、天文台、分类广告、谁说的、Junimo 宠物。内容都来自镇上真实发生的事。
- **使用帮助**：手机里的“使用帮助”应用，每个玩法怎么用、在哪里关都写在里面。
- **小工具**：完美度（各项进度和总分）、待办、番茄钟（按现实时间走，到点提醒）、生日日历、鱼缸（钓到过的鱼会游）、食谱、博物馆。
- **输入法候选框**：让输入法自己画候选字，中文输入更顺。
- **多语言**：界面跟着游戏语言走，支持中文、英语、日语、韩语、俄语、德语、法语、西班牙语、葡萄牙语、意大利语、土耳其语、匈牙利语（除中文外都是机器翻译，欢迎帮忙校对）。村民也用游戏语言说话。
- **设置**：可以搜索，每页能一键恢复默认；窗口大小能在 70%～150% 之间调；用不上的应用可以从应用页收起来。

### 信件、日记和礼物

- **来信**：村民给你写信，生日也会收到祝福。
- **日记**：每天一页，记下你和镇上发生的事，可以翻开日记本看。那晚 AI 没写成的话，第二天能点重试补上。日记写到某位村民时，会把他的一幅画夹进相册；整本可以导出成 PDF。
- **村民日记**：在村民页翻开某位村民的日记，看 TA 对你的感觉、今天的心事、想跟你说的、托你办的事、卷进的小剧场、和别人的关系、这些日子的变化、听信的传闻。
- **有名字的礼物**：村民送的东西有 AI 起的名字和一句亲口说的话，信里也能附。

### 约定和同伴

- **AI 提议**：聊完弹确认卡片（跟随、干活、约见、送礼），答应了就真的发生。
- **定时定点约见**：村民按真实路程走过去等你，守约有奖励，失约有代价。
- **日程改写**：约好的时间段里村民去指定地点，之后回到自己的日程。
- **邀约出游**：约村民出去逛，完成后加好感。
- **婚后伴侣剧情**：伴侣隔几天写一段小故事：信、请求、见面、有话想说。
- **配偶的一天**：婚后配偶每天早上排好安排：浇水、收菜、照顾动物、进鸡舍和温室干活、去镇上找人聊天、用自己的钱买东西、去小超市看店、带孩子在院子里玩；晚上汇总。手机“家务安排”应用里能看进度、领收获、关掉某一项。
- **跟随和帮工**：配合 The Stardew Squad，村民可以跟着你下矿、按心数收费干活、约好时间上门；帮工页能看到今天谁来、干什么、进度、花了多少、退了多少。

### 小剧场

- **故事线**：镇上发生一段段小故事，你参与推动结局，结局可以在游戏里演出来。
- **场景事件**：117 段写好的村民日常小场景，可以撞见，也可以旁听。
- **拜托和承诺**：村民托你办事、向你要东西，办完有一小段感谢戏。
- **孩子离家出走**：偶尔孩子会跑到农场上躲起来，配偶来报信；靠近时能听到笑声，路上有玩具当线索，找到了配偶松一口气。可以调概率或关掉。
- **离开小镇**：关系走到尽头时可能有人离开小镇（可调概率，孩子和配偶不会）。
- **节日对话**：节日里也是 AI 对话，可以邀请跳舞和组队；散场后大家还会回味。

### 村民自己的人生

- **心愿**：12 位村民各有一件想做成的事（海莉办摄影展、山姆的乐队登台、罗宾搭凉亭、格斯办美食节……），同时有几位在忙，每周可能往前走一步，进展传成八卦、上周报，聊天时也会提起。
- **托你帮忙**：走到某一步会托你找样东西，送到了更快达成。
- **达成**：村民来信请你去看，那一周去对的地方就能看到一段结局戏（场上摆着这件事的道具），日记里夹一幅画；有的人之后换了工作。
- **村民之间的恋爱**：暗生好感的两位可能交往、每周晚上约会，交往久了订婚，一周后在镇广场办婚礼，也可能分手。关系网里能看到，订婚、结婚以后家谱里也有。你在追求或已经娶嫁的村民不会和别人谈。

### 小镇经济

- **市场行情**：出货价每天波动，加工品跟着原料走。
- **委托板（村民→玩家）**：收购、采集、求矿、来坐坐，报酬按物品原价。
- **托村民办事（玩家→村民）**：找东西、代买、做菜、转送、干农活，报酬先托管。
- **村民账本**：钱包、存款、随身物品、家当、流水；会逛店、存钱、互相借钱，手头紧时按性格想办法（卖唱、打零工、登广告）。你也可以向村民借钱，或者在酒吧赊账。
- **农夫小超市**：在 Robin 那里建一间自己的小店（皮埃尔杂货店的样子），把收成、配偶做的东西、进来的货摆上货架卖给村民。详见下面一节。
- **家当会消耗**：家当每周用掉一些，AI 礼物优先从家当里挑。
- **分类广告**：AI 按各人口气写；离婚卖婚纱、被扒窃登寻物，有实物的可以直接买下。
- **《鹈鹕镇周报》**：AI 按最近的八卦写新闻，核对事实，带行情和委托，可以翻往期；只有单一来源的消息写成未经证实。
- **对话消耗时间**：聊完关掉对话框后钟一格格走，最晚到 25:50。

### 农夫小超市

- **在哪建**：Robin 的木匠铺 → 建造农场建筑 → 农夫小超市，建在农场上，从门口进店。店里已经摆好货架、冷柜、木柜、促销桶、收银台和仓库大箱子；更多货架在 Robin 店里买。
- **六种货架**：大货架、小货架、玻璃冷柜（鱼、蛋奶放这里更耐放）、保温柜（只放熟食）、促销桶（一样货，特别显眼）、木柜（加工品、矿石、文物、花）。拿着东西点货架就上架，空手点能改价、取下；货会摆在架子上看得见。
- **新鲜度和产地**：货从上架那天开始算新鲜，当天、新鲜、一般、快过期、过期，放错温度坏得快；自己种的、配偶做的会标出来，顾客更愿意买。
- **行情和店型**：每天有一类热门、一类冷门的货；每周可以选一次店型（杂货、蔬果、鱼铺、花店、熟食、工坊、古董），对口的货卖得更好。卖得越多店铺等级越高。
- **顾客**：村民按自己的习惯来逛，有随便看看的、买菜做饭的、买鱼的、买礼物的、肚子饿的、讲究品质的、收藏家；挑货看预算、口味和价格。
- **收银小游戏**：有人排队时点柜台，把篮子里的东西一样样扫过去，再用硬币凑出找零；又对又快有小费，找错了顾客会不高兴。不想玩可以在设置里关掉，改成自动结账。
- **评价和口碑**：顾客走时打一到五星，看找没找到想要的、价格、新鲜度、排队多久、店里漂不漂亮。星级越高来的人越多。
- **手机“小超市”应用**：概况（营业额、星级、等级、行情、店型）、进货（Pierre、Marnie、Willy、Gus、Clint、Evelyn，第二天早上送到仓库）、宣传（海报、橱窗、吆喝）、店员（收银、理货、迎宾，签 7 天或 28 天，好感越高工资越低）、评价。
- **市场竞争**：生意好了 Pierre 和 Joja 会难做，可能缩短营业时间、找上门来理论（可以讲道理、让一步，或者动手给对方一拳，会被镇长罚款）；从 Pierre 进货能帮他一把。卖赃物给失主可能被认出来：失主按自己的脾气当场翻脸，镇长罚款，之后记仇上门、被人取笑、上周报；同一季第 2 次停业整顿，第 3 次被带走（装了 Law and Order 关进牢里）。
- **和 Farmer's Store 同时用**：装了 Farmer's Store 也没关系，两家店各开各的，不抢顾客。
- **卸载前**：在 SMAPI 控制台输入 `aisv_store uninstall`，货会收回背包（放不下的装箱放在农场空地上），店变成原版大棚屋，货架拿掉，然后再删 mod。

### 做错事的后果

- **越犯越重**：在原有后果之外，同一季里犯得越多越重，换季清零。每种都能在 设置 > 后果 里单独关掉。
- **放人鸽子**：对方记成你说话不算话；第二回传开；第三回这一周不肯再和你约。
- **答应的事没办**：托付、请求到期没办，好感掉一点；第二回传开，大家说你不靠谱。
- **欠钱不还**：镇长来信；第三回起两周内谁也不肯借钱给你，格斯也不让赊账。
- **在店里动手**：第二回罚款加倍，第三回被带走，当天结束。
- **卖赃物、偷东西被抓、翻垃圾桶**：罚款和来信按次数加重，传开后被人起外号。
- **当着恋人调情**：对方来质问、伤心好几天；配偶这几天不帮你干农活。

### 分寸

- **儿童保护**：孩子不进群聊、约见、帮工、委托，也不会有感情戏。
- **成人内容默认关闭**：见下文“成人 mod”。私密时刻只记地点，不记内容。

## 兼容与联动

AI星露谷尽量直接从游戏数据里读取其他 mod 的内容，而不是为每个 mod 写死适配；同时对一些大型扩展和联动 mod 做了专门处理。

### 大型扩展与 NPC mod

- **星露谷扩展（SVE / Stardew Valley Expanded）**：SVE 的村民、作物、物品、住所、日程和礼物喜好都能接入；SVE 村民有单独的人设。
- **东斯卡普（East Scarp）、里奇赛德村（Ridgeside Village）等大型扩展**：新增的村民、作物、物品、日程等内容从游戏数据读取，不需要单独适配。
- **任意通过内容包向 `Data/Characters` 添加村民的 mod**：可以由 AI 接管，内容包可以写自己的人设字段。支持社区的 AI 排除名单，尊重不希望角色被 AI 驱动的作者。在 设置 > 常用 > 村民和 NPC mod 里能看到每位村民用不用 AI、为什么，也能关掉某位村民、选用哪些 mod 的村民。
- **Beach Episode**：沙滩排球锦标赛和鹦鹉之夜有节日对话。

### 联动 mod

- **The Stardew Squad（星露谷小队）**：同伴跟随、帮工、上门。发布包已内置带 API 的版本；自己编译时需要另装带 API 的版本，没有时这部分功能不可用，其他功能不受影响。
- **Stardew Thief（搜打撤）**：只读观察，不改它的行为。看见的人会找你理论，失主发现少了东西，镇上会传开。
- **Farmer's Store（农夫商店）**：两家店可以同时开。它占用的村民我们不拉来当顾客，我们的顾客和员工它也不会拉走；它那边的成交也算进村民账本和八卦。它默认用 F5/F6/F7，和本 mod 的 F6/F7 撞了，检测到时会提醒你改键。
- **Generic Mod Config Menu**：装了就能在里面改设置。
- **其他 mod 交八卦**：别的 mod 可以用 SMAPI 的 `ModRegistry.GetApi` 取得本 mod（`AIStardewValley.Core`）的接口，调用 `bool AddRumorNote(string text, string ownerModId)` 交一条今天发生的事，当晚整理八卦时一起考虑。接口定义见 `src/AISV.Mod/AiStardewValleyApi.cs`；玩家可以在设置里关掉，也能限制每天的条数。

### 成人 mod（可选）

- 专门识别 **Xtardew、Valley Girls、LAtardew、Polyamory Sweet** 的事件和对话；数据里只有识别信息，没有事件或对话原文。
- 成人模块默认关闭，需要在设置里手动开启。
- 只有玩家自行安装对应成人 mod 并主动开启时，相关联动才会出现；没安装时自动跳过，不会报错。
- 本项目本身不包含成人内容，也不会主动触发成人 mod 的事件；相关事件仍由原 mod 按自己的条件触发。

### 自动关闭原则

- 所有联动都会先检测目标 mod 是否已加载；没装就跳过，相关按钮和提示不会出现。
- 世界模块、同伴模块、成人模块都可以在设置里单独关闭。

## 安装与运行

1. 安装 [SMAPI 4.0+](https://smapi.io/)。
2. 将发布包解压到游戏的 `Mods` 文件夹（包里已含 The Stardew Squad）。[Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915) 是前置，需要另外安装，包里不带；没装时 AI 功能和 Squad 主体照常运行，但 Squad 的坐姿贴图和海莉、哈维的同伴内容包不会加载。
3. 启动游戏。发布版首次需要 AI 时在游戏内注册或登录账号；也可以跳过登录，村民会先说游戏原来的台词。
4. 想使用自己的 AI 服务时，到 设置 > 常用 > AI 连接 选择自己的网关，填入 API 地址与密钥（OpenAI 兼容接口），可以当场测试连接。密钥可以填好几把，用逗号隔开，一把不能用就自动换下一把。Ollama、LM Studio、llama.cpp、KoboldCpp 点一下就能填好地址。

使用内置服务器时，服务器会收到哪些信息、哪些可以关，见 [PRIVACY.md](PRIVACY.md)；游戏里在 设置 > 常用 > 数据说明。帮助改进功能的数据（游戏时长、各功能用了几次）默认开着，在 设置 > 常用 > 帮助改进功能 里可以关，关掉后不再收集。

> 目前仍处于早期开发阶段，接口、配置和存档结构可能继续调整。

## 从源码编译

需要 .NET 8 SDK（测试在 net8.0 上跑）和 .NET 6 目标包；编译 mod 还需要装好 SMAPI 的游戏目录。

```bash
dotnet build AISV.sln -c Release -p:GamePath="/path/to/Stardew Valley"
```

编译结果在 `bin/AIStardewValley`，放进游戏的 `Mods` 文件夹就能用。源码里没有服务器连接文件（`assets/connection.dat`），自己编译的版本只能用自己的 AI 网关。

运行单元测试（不需要启动游戏）：

```bash
dotnet test tests/AISV.Core.Tests
```
